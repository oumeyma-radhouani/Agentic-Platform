# ☁️ CloudShift : Plateforme Agentique d'Analyse de la Satisfaction Client

Ce dépôt contient le code source de la Plateforme Agentique d'Analyse de la Satisfaction Client et d'Aide à la Décision[cite: 4]. 

## Objectifs du Projet
Le système est conçu pour automatiser l'analyse linguistique des comptes-rendus d'appels et orchestrer la prise de décision métier en croisant ces retours avec les données opérationnelles du Système d'Information (SI) de CloudShift[cite: 4].

## Architecture Technique
La solution repose sur une architecture modulaire open-source[cite: 4] :
* **LlamaIndex :** Extraction et analyse sémantique des comptes-rendus non structurés[cite: 4].
* **LangChain :** Intégration et connecteurs vers les APIs du SI[cite: 4].
* **LangGraph :** Orchestration du workflow décisionnel et gestion de la mémoire des agents[cite: 4].
